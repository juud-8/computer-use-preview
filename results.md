1. **Obtain Model Response:**
   * The agent calls `get_model_response()` using the Google GenAI API (`client.models.generate_content`) passing in the historical conversation content (`self._contents`).

3. **Termination & Error Handling Check:**
   * **No-op / Malformed FCs:** If the model didn't call functions and did not generate reasoning, and its exit code is `MALFORMED_FUNCTION_CALL`, the iteration returns `"CONTINUE"` to retry.

4. **Action and Safety Processing:**
   * For each extracted tool/function call:

   * The tool results are appended to the main conversation list as a new `user` turn.
